### 코드가 실행되기까지

1. 폴더 생성
      -  Go 언어에서 모든 코드는 패키지 단위로 작성됩니다.
      -  같은 폴더에 위차한 .go 파일은 모두 같은 패키지에 포함되고, 패키지명으로 폴더명을 사용합니다.
2. .go 파일 생성 및 작성
      - 확장자는 반드시 .go로 끝나야 합니다. 
3. Go 모듈 생성
      - Go 1.16 버전 이후로 Go 모듈이 기본으로 적용됩니다. 따라서 모든 Go 코드는 빌드하기 전에 모듈을 생성해야 합니다.
      - 모듈 생성은 `go mod init 모듈 이름` 명령으로 실행합니다. 
      - Go 모듈을 생성하면 go.mod 파일이 생성됩니다. 파일에는 모듈명과 Go 버전, 필요한 패키지 목록이 담겨있습니다. 
4. 빌드
      - go build 명령은 Go 코드를 기계어로 변환하여 실행 파일을 만듭니다.
      - `GOOS`와 `GOARCH` 환경변수를 조절해서 다른 운영체제와 아키텍처에서 실행되는 실행파일을 만들 수 있습니다. 
5. 실행
      - 이렇게 만들어진 실행 파일을 명령어로 실행하면 됩니다. 

## 02장. 변수

### 변수란

- 변수란 값을 저장하는 메모리 상의 공간입니다. 값에 접근해 값을 변경하는 데 사용합니다.
- 변수는 이름, 값, 타입, 주소 속성을 갖습니다.
- 변수 간 값의 전달은 항상 복사로 일어납니다.
- 변수를 사용하면 메모리 공간에 이름을 부여하여 쉽고 효과적으로 메모리를 사용할 수 있습니다.

### 변수 선언

```go
// [변수 선언 키워드] [변수명] [타입] [초깃값]
var a int = 10
```

- 컴퓨터는 위 명령어를 실행할 때, 메모리에 정수 타입 데이터를 저장할 공간을 만들고 -> a라고 지칭한 뒤 -> 값 10을 복사합니다.
- 이제 a라는 변수명을 이용해서 해당 공간에 접근할 수 있습니다.

### 변수는 타입을 가지고 있다

- 타입이 필요한 이유 첫번째, 타입은 메모리 공간 크기를 알려줍니다.
      - 변수는 메모리 주소를 가리킵니다. 메모리 시작 주소만으로는 해당 메모리 주소에서 얼만큼 읽을지 결정할 수 없습니다.
- 타입이 필요한 이유 두번째, 타입을 알아야 컴퓨터가 데이터를 해석할 수 있습니다.
      - 2진수 1000 0000값은 uint8 타입으로 128이고, int8 타입으로 -128, float32 타입으로 1.79366203434e-43입니다.
      - 따라서 타입을 모르면 실제 어떤 값을 갖는지 알 수 없습니다.
- Go 언어는 숫자, 불리언, 문자열, 배열, 슬라이스, 구조체, 포인터, 함수, 인터페이스, 맵, 채널 등의 타입을 제공합니다.


### 변수 선언의 다른 형태

```go
var a int = 3 // 기본 형태
var b int // 초깃값 생략, 초깃값은 타입별 기본값으로 대체
var c = 4 // 타입 생략, 변수 타입은 우변 값의 타입이 됨
d := 5 // 선언 대입문 := 을 사용해서 var 키워드와 타입 생략
```

## 03장. fmt 패키지를 이용한 텍스트 입출력

### 표준 입출력

- 프로그램과 사용자는 입력과 출력을 통해서 상호작용합니다.
- 일반적으로 화면에 출력하고 키보드를 통해 입력 받습니다.
- 때로는 입출력을 화면이 아니라 파일, 프린터, 네트워크로 전송할 수 읽어올 수도 있습니다.

- Go언어에서는 fmt 패키지를 사용해서 간편하게 표준 입출력 처리를 할 수 있습니다.
      - 표준 출력 함수로는 `Print()`, `Printf()`, `Println()`이 있습니다.
      - 표준 입력 함수로는 `Scan()`, `Scanf()`, `Scanln()`이 있습니다.

## 05장. 함수

- 함수란 특수한 코드 묶음을 말합니다. 함수를 만들면 코드를 재사용할 수 있습니다.

```go
func Add(a int, b int) int {
      return a + b
}
```

- `func` 키워드를 사용해서 함수 정의를 알립니다. 그 뒤에 함수명이 옵니다. 
- 첫 글자가 대문자인 함수는 패키지 외부로 공개되는 함수입니다.
- 소괄호 안에 parameter를 넣습니다. parameter는 함수 코드 수행 시 필요한 입력 값이고 필요하지 않다면 비워둡니다.
- 소괄호 뒤에는 반환 타입이 옵니다. 반환하는 값이 있으면 적고, 아니면 비워둡니다.
- 중괄호로 함수 코드 블록을 표시합니다,.

### 함수를 호출하면 생기는 일

```go
c := Add(3, 6) // argument와 함께 함수 호출
func Add(a int, b int) int { // parameter 생성 및 초기화
      return a + b // 값 반환(복사)
} // 로컬 변수 삭제
```

- 여기서 핵심은 "argument는 parameter로 복사되며 parameter와 함께 함수내에서 선언된 변수는 함수가 종료되면 접근하지 못한다"입니다.

### 멀티 반환 함수

```go
func Divide(a, b int) (int, bool) {
      if b == 0 {
            return 0, false
      }
      return a / b, true
}
```

- 함수는 값을 여러 개 반환할 수 있습니다. 반환 값이 여럿일 때는 반환 타입들을 소괄호로 묶어 표현합니다.

## 06장. 상수

### 상수 선언

```go
// var 대신 const 키워드를 사용해서 상수를 선언합니다.
const ConstValue int = 10 
```

- 상수는 변하지 않는 값을 표현할 때 사용됩니다.
- 절대로 변경되면 안되는 값의 변경을 효과적으로 막아 안전하게 사용할 수 있습니다.
- 기본 타입(primitive)이 아닌 타입(complex)에는 상수를 사용할 수 없습니다.
      - 사용 가능 (불리언, rune, 문자열 정수, 실수, 복소수)
      - 불가능 (구조체, 배열 등)

### itoa로 간편하게 열거값 사용하기

```go
const {
      Red int = itoa // 0
      Blue int = itoa // 1
      Green int = itoa // 2
}
// 만약 첫 번째 값과 똑같은 규칙이 계속 적용된다면 타입과 itoa를 생략할 수 있습니다
const {
      C1 unit = itoa + 1 // 1 = 0 + 1
      C2                 // 2 = 1 + 1
      C3                 // 3 = 2 + 1
}

const {
      BitFlag1 unit = 1 << itoa // 1 = 1 << 0
      BitFlag2                  // 2 = 1 << 1
      BitFlag                  // 4 = 1 << 2

}
```

- 상수를 코드값으로 사용할 때 1, 2, 3.. 처럼 1씩 증가하도록 정의할 때 itoa 키워드를 사용하면 편리합니다.
- itoa는 0부터 시작해 1씩 증가합니다. itoa는 소괄호를 벗어나면 다시 초기화됩니다.

### 상수와 리터럴

```go
var str string = "Hello World"
var i int = 0
i = 30
```

- 컴퓨터에서 리터럴이란 고정된 값입니다.
- 위 코드에서 "Hello World", 0, 30과 값이 고정된 값 자체가 바로 리터럴 입니다.
- Go언어에서 상수는 리터럴과 같이 취급합니다. 그래서 컴파일될 때 상수는 리터럴로 변환되어 실행 파일에 쓰입니다.

```go
const PI = 3.14
var a int = PI * 100

// 컴파일 타임에 아래와 같이 변환됨
var a int = 314
```

- 상수 표현식 역시 컴파일 타임에 실제 결괏값 리터럴로 변환하기 때문에 상수 표현식 계산에 CPU 자원을 사용하지 않습니다.
- 상수의 메모리 주솟값에 접근할 수 없는 이유 역시 컴파일 타임에 리터럴로 전환되어서 실행 파일에 값 형태로 쓰이기 때문입니다.
- 그래서 동적 할당 메모리 영역을 사용하지 않습니다.
- 프로그램이 로드될 때 실행 파일이 올라간 영역을 코드 영역이라고 하고 프로그램 실행을 위해서 실행 중 할당해서 사용되는 영역을 동적 할당 메모리 영역이라고 합니다. 상수는 리터럴로 코드 영역에 포함되기 때문에 동적 할당 영역을 사용하지 않습니다.

## 07장. if문

### if문 사용법

- if문은 조건에 따라 프로그램 실행을 분기하는 구문입니다. 다음과 같은 형태가 있습니다.

```go
if 조건문 {
      문장
}
```

```go
if 조건문 {
      문장
} else {
      문장
}
```

```go
if 조건문1 {
      문장
} else if 조건문2 {
      문장
} else {

}
```

```go
// 초기문을 먼저 실행하고 조건 검사를 합니다.
if 초기문; 조건문 {
      문장
}
```

### 쇼트 서킷

- `&&` 연산은 좌변이 `false`이면 우변을 검사하지 않고 `false` 처리를 합니다.
- `||` 연산도 좌변이 `true`이면 우변을 검사하지 않고 `true` 처리를 합니다.

### if 초기문; 조건문

```go
if filename, success := UploadFile(); success {
      fmt.Println("Upload sucess", filename)
} else {
      fmt.Println("Failed to upload")
}
```

## 08장. switch문

### switch문 동작 원리

```go
switch 비굣값 {
case 값1:
      문장
case 값2:
      문장
default:
      문장
}
```

- switch 키워드 다음에 비굣값이 옵니다.
- 첫 번째 case부터 값을 검사합니다. 만약 비굣값과 case값이 같으면 해당 case 문장을 수행하고 switch문을 종료합니다.
- 같은 값이 없으면 default 문장을 수행합니다. default는 생략이 가능합니다.

```go

a := 3
switch a {
case 1:
      fmt.Println("a == 1")
case 2:
      fmt.Println("a == 2")
default:
      fmt.Println("a > 2")
}
```

### switch 초기문

- if문과 마찬가지로 `switch`문에서도 초기문을 넣을 수 있습니다.

```go
switch age := getMyAge(); age {
case 10:
      fmt.Prinln("Teenage")
case 33:
      fmt.Prinln("Pair 3")
default:
      fmt.Prinln("My age is", age)
}
```

### const 열거값과 switch

- `const` 열거값에 따라 수행되는 로직을 변경할 때 `swtich`문을 주로 사용합니다.

```go
type ColorType int // 별칭 ColorType을 선언하고 const 열거값을 정의
const(
      Red ColorType = itoa
      Blue
      Green
      Yellow
)

func colorToString(color ColorType) string {
      switch color {
      case Red:
            return "Red"
      case Blue:
            return "Blue"
      case Green:
            return "Green"
      case Yellow:
            return "Yellow"
      default:
            return "Undefined"
      }
}

func getMyFavoriteCollor() CollorType {
      return Blue
}
fmt.Println("My favorite color is", colorToString(getMyFavoriteCollor()))
```

### break 키워드

- 일반적으로 다른 언어에서는 `switch`문의 각 case 종료 시에 `break`문을 사용하지않으면 다음 case로 코드가 이어서 실행됩니다.
- 하지만 Go 언어에서는 break를 사용하지 않아도 case 하나를 실행 후 자동으로 switch 문을 빠져나가게 됩니다.

## 09장. for문

### 핵심 요약

- `for`문은 조건문이 `true`이면 코드 블록을 반복 수행합니다. `continue`와 `break`를 통해서 `for`문 후처리로 가거나 해당 반복문을 빠져나갈 수 있습니다.

```go
// 기본 형태
for 초기문; 조건문; 후처리 {
      코드 블록
}
```

```go
// 초기문 생략
for ; 조건문; 후처리 {
      코드 블록
}
```

```go
// 초기문, 후처리 생략
for ; 조건문; {
      코드 블록
}

// 또는 다음 처럼 ; 생략 가능 

for 조건문 {
      코드 블록
}
```

```go
// 초기문, 조건문, 후처리 모두 생략
for {
      코드 블록 // 무한 반복됩니다(break를 이용해 for문 탈출 가능)
}
```
